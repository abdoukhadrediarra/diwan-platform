Poem to JSON

Give the page a poem. It finds the muqaddima, the poem's name, the abyat and the khatima, and gives you the JSON to import into the database.

Opening text, then the poem's own name on its own line if it has one (otherwise its first sadr is used), then the abyat with | between the hemistichs, then the khatima.
