# Plateforme Diwan

Les sept diwans de Cheikh Ahmadou Bamba, vocalisés, transcrits et publiés poème par poème.

| Dossier | Partie | Démarrer |
|---|---|---|
| `backend/` | Django + PostgreSQL : base de données, API, administration, import des poèmes | voir `backend/README.md` |
| `frontend/` | Angular : le site web | voir `frontend/README.md` |
| `mobile/` | Flutter : l'application Android et iOS | voir `mobile/README.md` |

Le site et l'application lisent les mêmes données par l'API `/api/v1/` du backend.
Le document de référence technique (en français) explique les choix et les méthodes du projet.
